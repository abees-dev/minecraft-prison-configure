## Block 2 — Bắt đầu & mỗi ngày

```
📌 BẮT ĐẦU
/gang create <tên> <prefix>   — phí 100k→250k→500k→1M theo số bang server
Được mời: /gang accept | deny
Xin vào: menu Duyệt bang → chờ Leader/Co duyệt

Role: Leader (full) · Co (invite/sell/upgrade/quest Lv1) · Member (nạp + làm quest)

📅 MỖI NGÀY
1. Đào → nạp quặng vào /gang vault
2. Leader/Co: Bán Tất Cả → bank + danh vọng
3. /gang personal → claim (+5k + 20 danh vọng)
4. Leader/Co mở /gang quest nếu còn lượt
5. Check /gang koth (Mỏ VIP)
6. Tối 20:00 VN: /gang war join (Bang Chiến — đang dev)
```

## Block 3 — Bank / Vault / Nâng cấp

```
🏦 BANK & KHO
• Nạp quặng → +1 danh vọng / item
• Sell All (Leader/Co) → tiền vào bank, có nhân Sell / buff / paragon
• Nạp TIỀN vào bank: thuế 30% — ưu tiên nạp quặng rồi Sell All
• Bang Lv ≥ 3: mỗi người tự bật/tắt auto-nạp kho
• Cùng lúc chỉ 1 người mở kho

⬆ NÂNG CẤP (ưu tiên)
Sớm: Sell → Magnet → Quest (Capacity/Efficiency)
Muộn: Warlord / Protection / KOTH Control
Shop: mở rộng kho + buff tạm (Sell×2, Haste, EXP)

/gang bank nap|rut <số>
/gang upgrade · /gang shop · /gang vault
```

## Block 4 — Quest & KOTH

```

## Block 5 — Bang Chiến (đang phát triển)

```
⚔ BANG CHIẾN — ĐANG PHÁT TRIỂN TIẾP
Giờ: 20:00 (VN) · ~30 phút · world_pvp
Join: /gang war join  hoặc  /bangchien
Status: /gang war status

Luật cơ bản (có thể đổi):
• Chiếm 4 Cổng Xuất → +điểm/giây khi giữ độc quyền
• Kill player / boss → +điểm
• 2 mạng / người · hết mạng = loại
• Leader mua thêm mạng từ bank (giới hạn/trận)
• Cùng bang: không đánh nhầm (FF off trong trận)

⚠ Boss/lính auto-spawn & cân bằng điểm có thể chưa ổn định.
Thưởng thắng → bank + danh vọng + điểm mùa (số liệu có thể chỉnh).
```
